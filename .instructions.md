Project Instructions — Enterprise Supervisor-SQL-RAG Chatbot
=========================================================

Purpose
-------
This file records the persistent, repo-level instructions for developers and automated agents working on the Enterprise Supervisor–SQL–RAG chatbot. It captures hard rules, project conventions, runtime hooks, agent/skill names and locations, testing guidance, and a short list of ambiguous decisions that need confirmation.

Scope
-----
- Applies to the entire repository and runtime behaviour (particularly files under `src/`, `app.py`, `rag_ingestion.py`, `gemini_client.py`, and any Streamlit UI pages).
- Targets both human developers and automated code/agent customisations (Copilot/agents).

Hard rules (must enforce)
-------------------------
- Python 3.11+; use explicit type annotations (TypedDict, Optional, List, Dict).
- Follow PEP 8 formatting and repository lint rules.
- Use British English for user-facing copy and comments.
- Never embed secrets or API keys in source. Load secrets from `.env` via `config.py`.
- Streamlit UI rules (enforced): do not run agent execution loops directly in render calls; store chat and agent state in `st.session_state`; show progress via `st.spinner` and `st.status`; clean intermediate agent logs before final render.
- SQL agent: read-only only. Sanitize all inputs; enforce a default row limit (50) and inject `LIMIT` when missing. Disallow `INSERT`, `UPDATE`, `DELETE`, `DROP`, `ALTER` in agent-executed SQL.
- Vector DB: Qdrant is primary for document vectors. Supabase is canonical for auth and metadata (user profiles, roles, pointers).
- Orchestration: use LangGraph / StateGraph for Supervisor routing and structured state; supervisors may also use Gemini prompts for clarifying questions and routing decisions.
- Visuals: use Plotly for interactive charts and provide a PNG thumbnail for compatibility in Streamlit.

Preferences (soft rules)
------------------------
- Use `ChatGoogleGenerativeAI` / `google.generativeai` or `langchain-google-genai` wrappers for Gemini calls.
- Keep agents modular under `src/agents/`, auth under `src/auth/`, admin under `src/admin/`, and storage under `src/storage/`.
- History storage: pointer-only history in Supabase (store minimal metadata + Qdrant references) with a default retention of 90 days unless admin config overrides.

Auth, Admin & History
----------------------
- Use Supabase Auth for user login (email/password; optional social SSO). Use Supabase user profile to store `admin` boolean for admin gating.
- Admin UI: embedded Streamlit admin panel (visible only to admin users) for configuring database URIs, managing ingestion, and purging history.
- History policy: store pointers/metadata in Supabase and vectors/content in Qdrant. Default retention = 90 days. Admins may trigger manual purge via UI.

Required runtime hooks (function signatures to implement)
------------------------------------------------------
- Auth hooks: `on_login(user_id: str) -> None`, `on_logout(user_id: str) -> None`, `validate_session(token: str) -> Optional[str]`.
- Ingestion hooks: `on_source_uploaded(source: dict)`, `pre_ingest(source) -> dict`, `post_ingest(result: dict)`.
- Supervisor lifecycle: `before_route(query: str, state: dict)`, `after_route(results: dict, state: dict)`, `on_clarify(question: str, state: dict)`, `on_iteration_limit(state: dict)`.
- SQL hooks: `before_query(sql: str, ctx: dict) -> str` (sanitise / inject LIMIT), `after_query(rows: list[tuple], ctx: dict) -> None` (audit/log).
- Visualization hooks: `pre_visualise(df, intent) -> dict`, `post_visualise(fig, meta) -> dict`.
- History hooks: `on_message_store(user_id: str, transcript_meta: dict) -> None`, `on_history_purge(cutoff_date: date) -> None`.
- Admin hooks: `on_config_update(admin_id: str, config: dict) -> None`, `on_manual_purge(admin_id: str, params: dict) -> dict`.

Agent / Skill names and file locations (suggested)
-------------------------------------------------
- `src/auth/supabase_auth.py` — Supabase wrapper, login/logout, role checks.
- `src/agents/rag_agent.py` — RAG retrieval + Gemini answer synthesiser.
- `src/agents/sql_agent.py` — SQLAlchemy read-only executor with sanitiser and row limit enforcement.
- `src/agents/visualisation_agent.py` — DataFrame → Plotly fig + PNG tile.
- `src/agents/supervisor.py` — LangGraph adapter / StateGraph wiring, routing decision prompts.
- `src/agents/ingestion.py` — PDF/weblink extraction, chunking, embedding, Qdrant upsert.
- `src/storage/history_store.py` — History pointer writes to Supabase + query helpers.
- `src/admin/admin_ui.py` — Streamlit admin UI and actions.

Testing & verification
----------------------

- Integration tests: small Postgres test instance (or Docker), sample PDFs, and a Streamlit smoke test `streamlit run app.py`.
